# Scripts Collections

### Usage

```shell
curl -fsSL https://raw.githubusercontent.com/Omni-NCC/scripts/master/{script} | bash -s
bash <(curl -fsSL https://raw.githubusercontent.com/Omni-NCC/scripts/master/{script})

wget -qO- https://raw.githubusercontent.com/Omni-NCC/scripts/master/{script} | bash -s
bash <(wget -qO- https://raw.githubusercontent.com/Omni-NCC/scripts/master/{script})
```

### Windows computer bootstrap

See [Windows WinRM HTTPS bootstrap](utils/windows/README.md) for online initialization of Windows computers managed with PowerShell Remoting or Ansible.
